## Deskripsi
Repository ini berisi program Python 3 untuk menyelesaikan empat latihan pada Modul 3.

## Daftar soal
1. **Diskon minimarket:** pelanggan mendapat diskon 10% jika total belanja sama dengan atau lebih dari Rp100.000. Program menampilkan total belanja, diskon, dan total pembayaran.
2. **Kelulusan mahasiswa:** nilai akhir di atas 60 dinyatakan LULUS.
3. **Tahun kabisat:** menentukan apakah tahun yang dimasukkan merupakan tahun kabisat.
4. **Konversi suhu:** mengonversi Celsius menjadi Reamur dan Fahrenheit menggunakan rumus pada modul:
   - R = 4/5 × C
   - F = 9/5 × C + 32

## Cara menjalankan
Pastikan Python 3 sudah terpasang, kemudian jalankan:

```bash
python main.py
```

Pada Android, file `main.py` dapat dijalankan melalui aplikasi Python 3 seperti Pydroid 3.

## Struktur repository
- `main.py` — kode program untuk empat soal.
- `README.md` — informasi dan petunjuk penggunaan.
- `requirements.txt` — keterangan kebutuhan Python.
- `contoh_output.txt` — contoh pengujian program.
